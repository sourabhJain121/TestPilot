SPEC-AS-ORACLE AGENTIC TESTING & REMEDIATION

Autonomous Regression Testing & Three-Valued Defect Arbitration

TestPilot AI solves the fundamental fragility of LLM test generation. Instead of hallucinating arbitrary assertions or using flawed code as the oracle, TestPilot grounds boundary synthesis in AST structures and OpenAPI specifications, triaging failures with a Three-Valued Arbiter to eliminate false alarms and test debt.

1. Three-Valued Triaging Arbiter

Classifies every failure into TRUE_CODE_DEFECT, INVALID_TEST_ASSERTION, or SPEC_AMBIGUITY_OR_DEFECT via ChromaDB spec retrieval.

2. Deterministic & AST Boundary Matrix

Extracts 49 formal schema boundaries directly from OpenAPI schemas (e.g. exclusive minimums, enum sets) without stochastic LLM hallucination.

3. Closed-Loop Remediation

Generates targeted unified diffs, applies them in an ephemeral pytest sandbox, and only commits patches that turn failing boundary tests green.
