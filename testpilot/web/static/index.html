EVIDENCE-GROUNDED REGRESSION TESTING RESEARCH

TestPilot — Evidence-Grounded AI for Change-Aware Regression Testing

Repository Evolution → Specification-Grounded Testing → Three-Valued Failure Arbitration

TestPilot combines deterministic repository analysis with LLM-based reasoning to identify regression tests affected by code changes, generate specification-grounded boundary tests, and classify failures as code defects, invalid test assertions, or specification ambiguity.

1. Repository-Aware Regression Analysis

Identifies changed symbols and affected regression tests using Git, AST/Tree-sitter, qualified symbol identity, and repository-level code intelligence.

2. Specification-Grounded Testing

Extracts deterministic boundaries from OpenAPI specifications and combines them with repository context for boundary-oriented test generation.

3. Three-Valued Failure Arbitration

Classifies failures into TRUE_CODE_DEFECT, INVALID_TEST_ASSERTION, or SPEC_AMBIGUITY_OR_DEFECT using code, test, and specification evidence.

Handled Edge Cases & Uncertainty Mitigation

Generic Verbs ('run', 'handle', 'dispatch')

Enclosing class stacks and AST receiver type inference prevent matching generic verbs across independent subsystems.

Negative Controls & Empty Ground Truth

When expected ground truth is empty or 0/0, TestPilot reports 'N/A' rather than hallucinating 100% precision or recall.

Unresolved External Dependencies

Third-party library boundaries (e.g. Werkzeug) are tracked with explicit uncertainty scores and confidence degradation.
